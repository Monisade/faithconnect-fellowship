# FaithConnect Fellowship

A simple Christian fellowship website built with Node.js.

## About the Application

FaithConnect Fellowship is a simple web application created to provide information about a Christian fellowship. It includes the fellowship's vision, Bible verse, meeting information, and ways to get involved.

## Features

- Welcome section
- Fellowship vision
- Bible verse
- Fellowship meeting information
- Get involved section

## Technologies Used

- Node.js
- HTML
- Docker
- GitHub
